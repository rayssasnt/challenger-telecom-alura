# challenger-telecom-alura

# 📌 Objetivo
Este projeto foi desenvolvido como parte do desafio técnico da Telecom X, uma empresa de telecomunicações que enfrenta um alto índice de evasão de clientes. O objetivo foi realizar um processo completo de ETL (Extract, Transform, Load) e EDA (Exploratory Data Analysis) para identificar padrões de comportamento que levam ao cancelamento dos serviços.

# 🛠️ Tecnologias Ultilizadas
- Matplotlib
- Pandas
- Numpy
- Python
